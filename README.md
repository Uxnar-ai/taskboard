# 任务卡 taskboard · 网页上写卡，定时任务次日照着做

> 一个只服务于自己的任务卡站：登录后在网页上建卡、改状态、删除，卡片写成本地 markdown，第二天凌晨的自动化任务直接读同一批文件开工。一天最多 2 张，多出来的自动顺延到下一个空位。

[English](README.en.md) | 中文

## 这是什么

任务卡本来是散在 `tasks/` 目录里的 markdown，用编辑器改一次要翻文件、对字段。现在多一个入口：网页上建卡，落地的还是同一张 markdown，读取链路完全没变。

- **只读公开**：不登录能看全部卡片、今天该做什么；所有写操作（建 / 改 / 删 / 改状态）走会话认证，未登录调接口直接 401。
- **一天两张**：某天未结案的卡满两张就顺延，页面明示排到了哪天。规则简单可预测，不做优先级插队。
- **四种状态**：待做 / 执行中 / 已完成 / 明天收尾。「明天收尾」故意不写进结案集合，次日自然变成「过期 1 天」，正好就是收尾语义。
- **归档不删**：结案后移到 `archive/`，留着回溯那天答应过什么。

服务只跑在本机，对外由反向代理转发；卡片文件只有一份，硬盘上就是唯一数据源。

## 功能

- 浏览器里建卡，落地的仍是同一份 markdown
- 未登录可浏览，写操作一律 401
- 一天两张上限，自动顺延并在页面明示
- 四种状态：待做 / 执行中 / 已完成 / 明天收尾
- 结案归档不删除，可回溯
- 只读 JSON 接口给定时任务做备用通道

## 技术栈

Flask · 原生 JS · 本地 markdown 文件（无数据库）

## 运行

```bash
python server.py --port 8802
# 首次启动会在 data/ 生成账号密码，网页上登录即可建卡
```
